# 截图

把截图放在这里，然后在根目录 `README.md` 的「它长什么样」一节引用。

建议：

| 文件名 | 内容 |
|---|---|
| `home.png` | 首页（发现） |
| `player.png` | 播放页（三行歌词） |
| `lyrics.png` | 展开的完整歌词 |
| `options.png` | 右上角「…」播放设置面板 |
| `eq.png` | 均衡器 |
| `sblyric.png` | 状态栏歌词（悬浮在桌面/其它 App 上） |
| `notification.png` | 通知栏播放控件 |

建议宽度 1080px 以内，PNG，避免体积过大（单张控制在 500 KB 以内）。
